# Эмулятор командной оболочки (вариант 19)

Практическая работа по дисциплине «Конфигурационное управление».
Эмулятор языка оболочки UNIX-подобной ОС с графическим интерфейсом.

## Общее описание

Программа открывает окно, в котором работает диалог в стиле командной
строки: приглашение, ввод команды, вывод результата. Заголовок окна
строится по данным реальной ОС: `Эмулятор - [username@hostname]`.

Состояние этапов разработки:

| Этап | Содержание                          | Статус |
|------|-------------------------------------|--------|
| 1    | REPL, GUI, заглушки `ls`, `cd`      | готово |

## Структура проекта

```
src/shellemu/        исходный код
    cli.py           точка входа
    gui.py           графический интерфейс (tkinter)
    shell.py         ядро: разбор и выполнение команд (без GUI)
    parser.py        разбиение строки на команду и аргументы
    response.py      результат выполнения команды
    history.py       история ввода (клавиши «вверх»/«вниз»)
    sysinfo.py       данные реальной ОС (пользователь, хост)
    commands/        реализации команд
tests/               модульные тесты
run.sh, Makefile     запуск и сборка
```

## Описание функций

### Парсер

Строка ввода делится на слова по пробельным символам: первое слово —
имя команды, остальные — аргументы. Кавычек и подстановок нет.
Пустая строка игнорируется.

### Ошибки

* неизвестная команда: `foo: command not found` (код 127);
* неверные аргументы: например, `cd: too many arguments` (код 1).

Сообщения об ошибках выделяются в окне красным цветом.

### Команды (этап 1)

| Команда          | Поведение                                           |
|------------------|-----------------------------------------------------|
| `ls [арг...]`    | заглушка: печатает своё имя и аргументы             |
| `cd [арг]`       | заглушка: печатает своё имя и аргумент              |
| `exit`           | закрывает окно эмулятора                            |

### Интерфейс

* поле ввода внизу окна, `Enter` — выполнить строку;
* `↑` / `↓` — перебор истории введённых команд.

## Сборка, запуск и тесты

Требуется Python 3.10+ с модулем `tkinter`. Внешних зависимостей нет.

```bash
./run.sh            # или: make run
make test           # модульные тесты (GUI-тесты пропускаются без дисплея)
```

## Примеры использования

```
user@host:~$ ls -l /tmp
ls -l /tmp
user@host:~$ cd docs
cd docs
user@host:~$ cd a b
cd: too many arguments
user@host:~$ foo
foo: command not found
user@host:~$ exit
```
